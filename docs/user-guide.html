刷 QQ 空间

使用指南 · qzone-skill v1.0 · 让 AI 帮你读动态、点赞，全程不弹窗口

一、这个东西是干什么的

它是一个小工具，帮你在 QQ 空间里做两件事：

  • 读——把好友最近发的动态整理成一份清单（谁发的、说了什么、多久前、有没有图）
  • 赞——给指定的动态点赞，或者按你定的规则自动赞

整个过程用的是无窗口的浏览器：你看不到任何窗口弹出来，它就悄悄跑完了。

它不做这些

  • 不自动评论、不自动发说说、不加好友
  • 不保存你的 QQ 密码（登录只走手机扫码）
  • 不上传任何数据（所有请求都是浏览器直接连腾讯）

二、准备

需要说明
电脑Windows / macOS / Linux 都行
Node.js 22+在命令行输入 node -v 能看到版本号就说明装了
浏览器Windows 用系统自带的 Edge 即可；其他系统需要 Chrome
手机 QQ只在第一次登录时用一次
不会用命令行？没关系，整个流程只有几条命令，下面每条都写好了，复制粘贴即可。在文件夹空白处按住 Shift + 右键，选「在此处打开 PowerShell 窗口」，就有一个能粘贴命令的地方了。

三、第一步：登录（只需要做一次）

1

在 D:\qzone-skill 这个文件夹里，跑：

node scripts/qzone.mjs login
2

它会等 3 分钟，等着你扫码。同时把二维码存成一张图片，路径类似：

C:\Users\你的用户名\AppData\Roaming\qzone-skill\out\login-qr.png

打开这张图片，用手机 QQ 扫一下，手机上再点「确认登录」。

3

看到 "ok": true 就成功了。登录状态会存在电脑上，以后不用再扫。

{"ok": true, "uin": "123456789", "nickname": "你的昵称", "already": false}
二维码过期了怎么办？重新跑一遍 login 就行。它自己也会每 25 秒重新截一次图，过期前扫都有效。

四、第二步：看看有什么动态

node scripts/qzone.mjs feed --pretty

会输出一份清单，长这样：

{
  "ok": true,
  "count": 12,
  "items": [
    {
      "key": "abc123",
      "name": "张三",
      "text": "今天去看了海，风很大但很舒服",
      "time": "3小时前",
      "liked": false,
      "hasImage": true
    }
  ]
}
字段意思
key这条动态的编号，点赞时要用它
name谁发的
text正文（太长会截断到 500 字）
time什么时候发的，是空间显示的原始文案
liked你是不是已经赞过了
hasImage带不带图

想多看几条就把 --limit 调大，比如 feed --limit 25。每多读一点就要多滚屏，读满大约 23 条、1 分钟。

更省事的用法：摘要

feed 会把所有字段都吐出来，信息全但啰嗦。日常更推荐用 摘要：

node scripts/qzone.mjs learn            # 先学一次你的口味
node scripts/qzone.mjs digest --images  # 看摘要，顺带把配图下到本地

digest 做的事：

  1. 读一遍好友动态
  2. 按你赞过谁给每条打分 —— 你常赞的人，内容排前面
  3. 只给你最值得看的 8 条（可以 --top 15 改）
  4. 带图的会把第一张图下载下来，直接能看
为什么要有这个：完整数据一次三千多 token，摘要只要三百多 —— 省 90%。而且顺序是按你自己的口味排的，不是按时间堆。

只想看上次之后的新内容，加一个 --since：

node scripts/qzone.mjs digest --since

口味是怎么学的

只从一件事上学：你赞过谁。你赞得越多的人，TA 的内容在摘要里排得越前。

这不需要你打标签、设偏好，也不靠猜测。想更新口味就再跑一次 learn，比如每周一次。

「很多人赞过」和「你赞过」是两件事。摘要排序看的是你的赞，不是总赞数 —— 所以刚用的时候排序可能不准，用几天、赞几次之后就准了。

五、第三步：点赞

手动赞指定的

node scripts/qzone.mjs like abc123

可以一次给多条：like abc123 def456。两条之间会隔 8 秒，这是为了防止触发风控。

自动赞（按规则）

先设置规则，再打开开关。规则的配置命令形如「键 值」：

# 只赞 24 小时内的动态
node scripts/qzone.mjs config auto.like.maxAgeHours 24

# 一次最多赞 10 条
node scripts/qzone.mjs config auto.like.maxPerRun 10

# 只赞这两个人（留空 = 不按人筛）
node scripts/qzone.mjs config auto.like.allowUsers "张三,李四"

# 永远不赞这个人
node scripts/qzone.mjs config auto.like.denyUsers "某某"

# 正文含这些词就不赞
node scripts/qzone.mjs config auto.like.denyKeywords "求转发,广告"
强烈建议先试运行一次，看看它会赞哪些、跳过哪些，确认没问题再真的开： 
node scripts/qzone.mjs auto --dry-run --pretty

真正开启

# 打开开关
node scripts/qzone.mjs on

# 挂成定时任务，每 30 分钟跑一次（关掉窗口也会跑）
node scripts/qzone.mjs service install --interval 30

想停下来的三种方式

命令效果什么时候用
pause立刻停手，不改配置临时不想让它动，等下还要继续
off关掉自动刷开关不想要自动赞了
service uninstall卸掉定时任务彻底不让它自己跑

恢复用 resume（对应 pause）和 on（对应 off）。

六、常用命令一览

命令作用
node scripts/qzone.mjs login扫码登录
node scripts/qzone.mjs status看登录了没、开关开没开
node scripts/qzone.mjs feed读动态
node scripts/qzone.mjs digest看摘要（推荐，最省）
node scripts/qzone.mjs digest --images摘要 + 看配图
node scripts/qzone.mjs learn学一次口味
node scripts/qzone.mjs like <编号>给指定动态点赞

node scripts/qzone.mjs on / off开 / 关自动刷
node scripts/qzone.mjs pause / resume紧急停 / 恢复

node scripts/qzone.mjs service install挂定时任务
node scripts/qzone.mjs logout退出登录

七、文件都在哪

代码在 D:\qzone-skill。你自己的数据不在代码里，在：

C:\Users\你的用户名\AppData\Roaming\qzone-skill\
├─ config.json     你的设置
├─ state.json      赞过哪些（用来去重，不用手改）
├─ browser\        登录状态（等于你的账号，别发给别人）
├─ out\            二维码、截图
└─ logs\auto.log   定时任务的运行日志
browser 这个文件夹等同于你的 QQ 空间登录状态。不要打包发人、不要传到网盘。要退出登录就运行 logout，它会把这个文件夹删掉。

八、常见问题

读出来是 0 条

八成是登录失效了。跑 status，看 loggedIn 是不是 false；是的话重新 login。

点赞说「点了但状态没变」

通常是赞得太频繁被风控了。停下来，隔几个小时再说，不要连着试，越试越糟。

定时任务装了但没动静

先看日志有没有新内容：

Get-Content "$env:APPDATA\qzone-skill\logs\auto.log" -Encoding utf8 -Tail 20

没有新内容就查任务在不在：node scripts/qzone.mjs service status。

想让 AI 自己去刷

把 SKILL.md 给你的 AI（比如支持技能的助手）就行。里面写清了每个命令怎么用、什么时候不该用。

会不会被封号

说实话：这是非官方用法，有风险。频率低风险小，但没法向你保证。默认参数（8 秒一条、一次最多 10 条）是保守值，不建议调高。

九、一句话总结

  1. login 扫一次码
  2. feed 看一眼
  3. auto --dry-run 预演一下
  4. on + service install 开起来
  5. 想停就 pause 或 off
